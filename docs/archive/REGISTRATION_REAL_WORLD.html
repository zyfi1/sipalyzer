Real-World Layouts

How actual products handle lists of items with status, actions, and metadata in 2025/2026. No invented aesthetics — just proven patterns from apps you already use.

Style 1

Linear-Style Dense List

Inspired by: Linear, GitHub Issues, Jira

Compact rows with status dot, inline metadata, and grouped sections. Keyboard-driven. Status is a priority icon, not a badge. Maximum density, minimum noise.

Best for: 5-50 registrars. Users who value density and keyboard shortcuts. When the list IS the primary workspace.

Better Stack / Uptime Monitor

Inspired by: Better Stack, UptimeRobot, Checkly, Pingdom

Status bar on the left edge, sparkline showing uptime history, and uptime percentage. Designed for monitoring — because registration IS monitoring. The sparkline tells a story that status dots can't.

Style 5

PagerDuty Incident List

Inspired by: PagerDuty, OpsGenie, Statuspage, FireHydrant

Summary counters at the top, tab filters, urgency bars on rows, and bulk action checkboxes. Designed for incident response — because a failed registration IS an incident.
