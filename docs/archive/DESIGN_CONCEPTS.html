SIPalyzer Design Depth Concepts

Visual mockups for solving the "flat" surface problem. Each concept targets a specific depth technique drawn from 2025/2026 design trends (Linear, Raycast, Warp, Arc, visionOS, Material 3, Vercel). Concepts can be combined — the final section shows recommended stacks.

A Bright Edge — Top-Light Inset

Simulate overhead lighting with a 1px bright inset shadow at the top of every elevated surface. This is how Apple visionOS, Linear, and Vercel's dashboard achieve glass depth on dark backgrounds. The existing shadow-dropdown already uses this technique — extend it to shadow-card.

Used by: Linear, Vercel, Apple visionOS, Figma, Notion dark mode

B Wider Lightness Range

Stretch the lightness gap between surfaces. Currently only 14 points of lightness separate the background (7%) from the brightest surface (21%). Modern dark UIs (Material 3, GitHub dark, Arc) use a 20-25 point spread. Darkening the base and lightening surfaces creates visible separation.

Used by: Material Design 3 elevation system, GitHub dark mode, Arc Browser

C Chromatic Lift — Hue Shift Per Elevation

Subtly shift hue and saturation as surfaces rise. Higher surfaces get slightly warmer and more saturated. Our brains naturally read warmer tones as closer. Material Design 3 calls this "tonal elevation," and Arc Browser uses it extensively.

Used by: Material Design 3, Arc Browser, Spotify (2025 redesign)

D Grooved Panels — Inset Wells + Raised Chrome

Add "physical" texture by creating inset content wells and raised chrome bars. Content areas sink into the panel, toolbars sit above. This is the technique Linear, Raycast, and Warp use to create their signature tactile depth.

Used by: Linear, Raycast, Warp Terminal, macOS System Preferences

E Gradient Surfaces — Directional Light

Replace flat bg-card/80 with a subtle top-to-bottom gradient simulating overhead light. Panels are brighter at the top and darker at the bottom. Arc Browser and Warp use this extensively — it creates natural, physically plausible depth without adding borders.

Used by: Arc Browser, Warp, Camo, Craft, Superhuman

G Luminous Borders — Gradient Top Edge

Instead of uniform borders, use a gradient highlight that fades from center-bright to edge-transparent along the top of cards. This mimics how real glass panels catch light — brightest at center, fading at edges. More dramatic than Concept A but still subtle. Stripe's dashboard pioneered this in 2024.

Used by: Stripe Dashboard, Resend, Vercel's new card style (2025)

H Noise Texture — Surface Grain

Add an ultra-subtle SVG noise grain overlay (2-3% opacity) to card surfaces. This breaks the digital "too-clean" look and makes surfaces feel physical/material. The app background already uses this technique — extending it to card surfaces adds tactile quality. Linear, Craft, and Apple's visionOS windows all use this.

Used by: Linear, Craft, Apple visionOS, Liveblocks

I Elevation Rings — Layered Multi-Shadow

Replace the single shadow with a 4-layer shadow system: bright ring → dark ring → key shadow → ambient shadow. Research shows layered shadows achieve 31% higher perceived quality ratings vs single shadows. This is the Material Design 3 elevation model adapted for dark themes.

Used by: Material Design 3, Resend, Planetscale, Railway

J Frosted Layered Glass — Dark Glassmorphism 2026

The defining 2026 dark UI aesthetic: frosted glass with higher blur (20px), subtle gradient fill, ultra-thin bright border, and saturate filter to make underlying content pop through. This is the "next-level" version of the current backdrop-blur-sm treatment. Currently only used on popovers — extend a toned-down version to panel surfaces.

Used by: Apple visionOS, Linear Liquid Glass (2025), iOS 19 concept UIs

Recommended Stacks — Combining Concepts

These concepts are designed to layer. Here are three recommended stacks from conservative to bold.

Stack 1 — Conservative
A + B + I
Bright Edge + Wider Lightness + Elevation Rings.

Pure CSS variable changes, zero component refactoring. Darkens the base, brightens the cards, adds visible edges and proper layered shadows. Immediately fixes the "everything blends" problem with the lowest risk of breaking anything.
~5 CSS vars 30 min
Stack 2 — Modern
A + B + C + D + E
Bright Edge + Wider Range + Chromatic Lift + Grooves + Gradients.

The "Linear/Raycast" tier. CSS variables + utility classes. Cards have visible edges, gradient fills, chromatic elevation, and grooved content wells. Requires adding surface-well and surface-raised utilities to key views.
CSS vars + utilities 2–3 hours
Stack 3 — 2026 Premium
A + B + C + G + H + J
Full dark glassmorphism stack.

Frosted layered glass + luminous borders + noise texture + chromatic lift + wider range. Every surface has visible depth, physical texture, and directional light. Requires new utility classes and applying them across views, but the result is the premium tier — Linear, visionOS, Vercel-caliber polish.
Full redesign 4–6 hours
